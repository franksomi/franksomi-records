# Franksomi Records — web app prototype

Files: index.html, app.js, style.css, config.js, logo.png (the website) and schema.sql (the database).
The `test/` folder is only for developer testing; do not upload it.

## Set up (about 30 minutes, all free tiers)
1. **Database + login — Supabase**
   - Create an account at supabase.com, then New project (pick the region closest to Kenya, e.g. Europe/Frankfurt or Bahrain-nearest offered). Save the database password.
   - SQL Editor -> New query -> paste all of `schema.sql` -> Run.
   - Authentication -> Providers -> Email: turn **off** "Allow new users to sign up" AFTER you create your own account (so nobody else can register).
   - Authentication -> Users -> Add user -> your email + a strong password (tick "Auto confirm"). **The first user created becomes the Owner.** Add each staff member the same way; they become Staff.
2. **Connect the site** — Project Settings -> API: copy the Project URL and the `anon` public key into `config.js`.
3. **Publish — Netlify (or Vercel / Cloudflare Pages)**
   - app.netlify.com -> Add new site -> Deploy manually -> drag the folder (without `test/`) in. You get a https link; add it to the phone home screen.
4. Sign in, add your suppliers, stock items and start recording. Add the first stock item before recording sales or repairs with parts.

## Roles
- **Owner:** everything, including deleting records, the money totals on the Dashboard, and the Lists.
- **Staff:** add and edit repairs, sales, jobs, stock, documents. Cannot delete, and the Dashboard hides money totals.
- To promote someone: Supabase -> Table Editor -> profiles -> change `role`.

## Honest limits of this prototype
- Staff are blocked from deleting and from the dashboard money totals, but a technical staff member could still read cost and profit columns through the database API. If staff must never see costs, a later version should split those columns into an owner-only table.
- No automatic backup beyond Supabase's free-tier daily backups (check the plan). Export tables to CSV regularly (Table Editor -> Export).
- Free Supabase projects pause after a week of no use; opening the site weekly avoids that.
- Works online only (not offline yet).
- Documents are not KRA eTIMS invoices. If you must issue tax invoices, use KRA's eTIMS for those.
- Phone numbers and serial numbers are stored as text. Item codes (e.g. PA-0001) are generated by the database.
